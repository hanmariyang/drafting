# 디자인 시스템 v1 · "AI 제안 모드"

> 정본. 모든 화면·컴포넌트는 이 문서를 따른다. v1 확정 2026-08-20.
> 제품 철학 한 문장: **"AI가 쓴 모든 것은 제안으로 들어오고, 수락해야만 문서가 된다. 당신이 편집장이다."**

## 0. 문법 규칙 (불변식 — UI 이전에 제품 규칙)

1. **AI 산출 = 항상 제안(proposed) 상태**로 들어온다. 자동으로 문서가 되는 AI 텍스트는 존재하지 않는다.
2. **수락(accept)된 것만 문서다.** 내보내기(MD·HTML·xlsx)·공유 링크에는 수락된 것만 포함된다.
3. **모든 제안에는 근거(source)가 붙는다** — 인터뷰 답(Q3), 상위 문서 조항(PRD §2), 또는 사용자의 고쳐쓰기 지시.
4. 제안 처리는 3택: **수락 / 거절 / 고쳐쓰기 지시**(텍스트 입력 → AI가 새 제안으로 회신).
5. 상위 문서가 바뀌면 영향받는 하위 항목은 **다시 제안 상태로 돌아온다**(stale 전파의 UI 표현).
6. **제안 그린은 상태 전용 색이다.** 장식·브랜딩 요소에 남용 금지 — 화면에 초록이 보이면 그것은 반드시 "검토할 것"이다.
7. 이모지 아이콘 금지(글리프·모노 텍스트), 좌측 컬러 액센트 바 금지, em-dash 금지(· 사용).

## 1. 토큰 (web/src/styles/tokens.css 와 1:1)

### 색
| 토큰 | 값 | 용도 |
|---|---|---|
| `--paper` | #FFFFFF | 에디터·카드 표면 |
| `--bg` | #F7F7F5 | 앱 배경·사이드 영역 |
| `--ink` | #1B1C1E | 본문·확정 텍스트 (제안이 수락되면 이 색으로 "마른다") |
| `--sub` | #6F7076 | 보조 텍스트 |
| `--hair` | #E7E6E2 | 헤어라인 보더 |
| `--sug` | #0E7B62 | **제안 상태** (브랜드 = 이 상태색) |
| `--sug-bg` | #E9F5F1 | 제안 하이라이트 배경 |
| `--sug-line` | #BFE3D8 | 제안 요소 보더 |
| `--del` | #AA3333 | 삭제 제안 (취소선) |
| `--ok` | #1B7F4B | 저장됨 등 시스템 정상 (제안 그린과 톤 구분: 채도 낮음) |
| `--hover` | #EFEFEB / #EAEAE5 | 리스트 hover / active |

다크 모드는 v2 과제 (토큰 구조만 대비해 둠 — 값 하드코딩 금지, 전부 var 경유).

### 타이포
- **sans**: Pretendard, -apple-system, "Segoe UI" (UI·본문 공통)
- **mono**: ui-monospace, "SF Mono", Menlo — ID(REQ-01)·버전·근거 태그·상태바 전용
- 스케일: 문서 제목 26/800/-.4px · 섹션 제목 15/800 · 본문 14.5, line-height 1.95, **max-width 640px** · UI 13 · 카드 12 · 메타(mono) 10~11
- 본문 단락은 원고답게 여유(1.95) — UI 텍스트는 1.5~1.6

### 공간·형태
- spacing 4px 그리드 · 창 radius 14 · 카드 10 · 버튼 7 · 배지/칩 99(pill)
- 그림자 최소: 제안 카드 활성 시에만 `0 2px 10px rgba(14,123,98,.1)`

## 2. 레이아웃 (데스크톱 앱 셸)

```
┌ tbar 42px: [신호등] [breadcrumb: 프로젝트 / 문서] ─── [●제안 N] [버전][공유][내보내기(pri)] [⌘K]
├─ shell: grid 236px | 1fr | 292px
│   nav(체인 트리)   editor(paper)   panel(제안 큐)
└ statusbar: [로컬 저장됨] [제안 태그라인] ──── [오프라인 OK] [모델] [버전]  · mono 10px
```
- **nav**: 프로젝트명 + "문서 체인" 그룹. 노드 = 타입 배지(mono 캡슐) + 이름 + **제안 수 그린 도트**(있을 때만). 계층은 들여쓰기+헤어라인 체인선.
- **editor**: paper 배경, 문서 헤더(eyebrow mono / 제목 / 메타), 본문.
- **panel**: bg 배경, "제안 N · 모두 수락" 헤더 + 제안 카드 목록 + 처리 통계 라인.
- 좁은 창(<1100px): panel 은 우측 슬라이드 오버(토글), nav 는 접힘.
- statusbar 좌측 두 번째 슬롯은 항상 제품 태그라인 계열 카피: "수락하지 않은 문장은 문서에 없습니다" / "제안 N · 수락 전에는 내보내기에 포함되지 않습니다".

## 3. 컴포넌트

### 제안 텍스트 (선형 문서 인라인)
- 추가 제안: `--sug-bg` 배경 + `--sug` 1.5px 밑줄 + 텍스트 #0B5C4A. 클릭 → 해당 카드 포커스.
- 삭제 제안: `--del` 취소선 + opacity .7.
- **앵커**: 제안 뒤 16px 그린 원 숫자. 카드 hover ↔ 본문 하이라이트 왕복(Docs 문법).

### 제안 카드 (panel)
```
[AI 아바타(그린 원)] [제안 제목(굵게)]        [근거: Q1 · mono]
설명 한두 문장
┄ 인용(변경 전→후, 있을 때만)
[수락(그린 pri)] [거절]           ← 즉시 처리
[고쳐쓰기 지시 input]             ← 3번째 선택지
```
- 활성 카드: `--sug` 보더 + 그린 섀도.
- 카드 유형: 추가/보강/삭제 제안 · **누락 질문**(답하기/넘기기) · stale 재검토("상위 PRD §2 변경으로 재검토 필요").

### 트리 문서 행 (기능명세·IA)
- 기본 행: ID(mono) + 제목 + 우측 메타. 들여쓰기 lv1/2/3 = 12/36/62px.
- **제안 행**: `--sug-bg` 배경 + ID 그린 + 우측 "제안됨" pill + 행 끝 ✓/× 미니 버튼(22px). 카드에서도 같은 제안 처리 가능(양방향).
- 좌측 보더로 상태 표현 금지(규칙 7) — 배경+pill 로만.

### 버튼
- 기본: paper + hair 보더 · **pri**: ink 배경 흰 글자 · **수락**: sug 배경 흰 글자 (수락만 그린 버튼 — "그린 버튼=문서에 넣기"의 일관성)

### 배지·카운터
- 상단 `● 제안 N`: sug-bg pill. 트리 그린 도트. 이 두 요소가 앱 전역의 "검토 안내판".

## 4. 화면별 적용

- **홈(프로젝트 목록)**: bg 배경 카드 그리드. 카드에 제안 수 도트. "새 프로젝트" pri 버튼.
- **문서(모든 타입)**: §2 셸. PRD=인라인 제안, 기능명세/IA=행 제안 — 문법 동일.
- **인터뷰**: v1은 기존 플로우 유지하되 이 토큰으로 리스킨(질문 카드+선택지 버튼). 인터뷰의 답 → 이후 제안 카드의 "근거 Qn"으로 연결.
- **설정**: 표준 폼, 키 상태만 ok 그린.
- **온보딩**: 첫 실행 1장 — 제품 철학 한 문장과 제안 문법 미니 데모.

## 5. 모션 (절제)

- 제안 수락 시: 하이라이트 배경이 200ms 로 걷히며 잉크색으로 (opacity 트랜지션) — "마르는" 순간.
- 카드 처리 시: 카드가 접히고 다음 카드가 올라옴(height/transform 180ms ease-out).
- prefers-reduced-motion 존중. 그 외 장식 모션 금지.
