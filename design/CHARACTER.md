# 초안이(Choani) — 캐릭터 정본 v1

> Drafting 의 마스코트이자 심볼. 코드 정본은 `web/src/components/Choani.tsx`, 모션은 `web/src/styles.css` 의 `ch-*` 키프레임. 이 문서와 코드가 어긋나면 코드를 이 문서에 맞춘다.

## 정체성

- **초안 종이 한 장**. 팔다리 없음 — 감정은 전부 **종이 물성**(기울기·접힘·말림·구겨짐)과 눈·입으로 표현한다.
- 역할: **제안을 물어오는 조수**. 편집장(사용자)의 판단을 돕되 평가하지 않는다.
- 형태 규칙: 지배적 실루엣 1개, 큰 기본 도형 4~7개, 3색(잉크 `--ink` · 제안 그린 `--sug` · 종이 `--paper`).
- 외곽선 **B = 3.2** (2026-08-20 확정). 비례: 접힘·구김 2.9 / 입 2.1 / 평평 입 2.0 / 선 2.7 / 눈웃음·X눈 2.3.

## 포즈 8종

| pose | 이름 | 쓰임 | 고유 모션 |
|---|---|---|---|
| `base` | 기본 | 로고·아이콘 | 깜빡임만 |
| `greet` | 인사 | 시작 화면·온보딩 | 좌우 끄덕 (ch-rock) |
| `fetch` | 물어옴 | 제안 카드 아바타 | 쪽지 쫑긋 (ch-tagbob) |
| `write` | 작업 중 | 초안 스트리밍 스트립 | 연필 긋기 루프 (ch-draw/pen) |
| `think` | 생각 | 질문·재작성 대기 | 점 3개 순차 점멸 |
| `wait` | 기다림 | 빈 상태 | 느린 숨 (ch-bob) |
| `done` | 완료 | 세리머니 1회 한정 | 스파클 교차 — 그린 장식 예외 허용 |
| `error` | 구겨짐 | 에러·서버 다운 | 이따금 부르르 · **그린 소등** |

크기 사다리: **<24px 얼굴만** · **<48px 얼굴+도트** · 이상 풀 포즈 (`fetch`는 쪽지가 정체성이라 소형에서도 유지, `error`는 항상 풀).

## 운용 3원칙 (불변)

1. **저빈도에 몰기** — 에디터·트리·패널 상시 화면에 등장 금지. 첫 실행·빈 상태·완료·에러에만.
2. **문서 영역 불가침** — 에디터 본문에 절대 들어가지 않는다.
3. **판단에 무표정** — 수락/거절 순간 캐릭터 반응 없음. 평가·애원 금지.

## 보이스

1인칭 존댓말("제가 물어왔어요") · 2문장 이내 · 다음 행동 안내로 끝맺기.
금지: 사용자 판단 평가("좋은 선택이에요!"), 애원("수락해주세요"), 느낌표 남발.

| 순간 | 카피 |
|---|---|
| 시작 화면 | 무엇을 만들까요? 한 줄이면 제가 인터뷰를 열게요. |
| 스트리밍 | 초안을 쓰는 중이에요. 다 쓰면 전부 제안으로 보여드릴게요. |
| 제안 도착 | 인터뷰 답을 근거로 N건 물어왔어요. 수락한 것만 문서가 돼요. |
| 빈 큐 | 검토할 제안이 없어요. 문서를 이어 쓰면 다시 물어올게요. |
| stale | 위 문서가 바뀌어서 다시 살펴볼 게 생겼어요. |
| 완성 | 체인이 완성됐어요. 수락 N · 거절 M — 전부 당신의 판단이에요. |
| 에러 | 제가 좀 구겨졌어요. 로그를 보고 다시 펴주세요. |

## 모션 규칙

- 등장: 아래서 10px 팔랑 550ms(살짝 오버슈트) 1회.
- idle: 깜빡임(4.6s) + 포즈 고유 모션 1개만. 이동·순회 등 큰 모션 금지.
- 강도 사다리: 문서에 가까울수록 조용 — 제안 카드 아바타는 `animate=false`(정지).
- `prefers-reduced-motion`: 전부 정적.
